\begin{abstract}
MEMO-Appflow 是面向 Android 的端侧应用预测与系统调度系统。它不只观察用户打开了哪些应用，也在手机内部持续采集 eBPF 内核证据和系统状态，将 app 序列、网络、Binder、内存、显示、媒体和进程信号按时间窗口压缩为 MAPLE 场景输入。端侧 MAPLE 模型据此预测接下来可能使用的 Top-3 真实应用，并输出 \texttt{scheduler\_bits} 选择预先实现的系统调度动作。Android 端随后更新桌面 Widget，并执行 warm launch、memory trim、service manager refresh 等动作。本文按照最终成功的系统版本组织，说明端侧流水线、数据结构、模型接口、动作执行和实验结果。真实 Pixel 5 实验显示，Top-3 推荐可以随 3 分钟窗口更新；30 条真实记录预测实验中，app+OS/eBPF 配置在 Top-3 Hit、F1@3 和 MRR 上高于 app-only baseline；系统调度性能实验中，Stage 3 调度使同一 Top-1 应用 QQ 的 Launch TotalTime 从 433 ms 降至 168 ms，WaitTime 从 440 ms 降至 173 ms，综合压力分数从 422.56 降至 9.71。
\end{abstract}
